# Julian Cichor

Prywatna strona wizytówkowa Juliana Cichora, poświęcona marketingowi internetowemu.

## Zawartość

- `index.html` — główna strona wizytówki
- `assets/` — zdjęcia użyte na stronie

## Uruchomienie

Otwórz plik `index.html` w przeglądarce. Strona nie wymaga instalacji ani dodatkowych narzędzi.
